开始前，先知道三件事

这三件事决定了你怎么保存数据、怎么理解结果。

1. 数据在浏览器里

自动暂存和“我的方案”都保存在当前浏览器。清理浏览器数据、换浏览器或换电脑后，不会自动带过去。重要数据请下载“项目备份”。

2. 结果是测算，不是预测

报告按你输入的参数和假设计算。案例标签、税率、价格和基准收益率都会影响结果；报告不能替代可行性研究、审批或投资决策。

3. 数字不合适，不一定是坏了

“未达标”“未回收”或 IRR 显示“—”，都是计算结果或求解状态，不是软件崩溃。先检查参数和判断基准，再看报告中的解释。

你需要准备

  • 一台电脑（Windows / macOS 均可），推荐 Chrome 或 Edge。
  • 能打开网页的网络。
  • 不需要安装 Excel 插件、Word 插件或任何客户端。
本说明的练习路线：使用内置的【虚拟】教学案例，不涉及真实项目。案例中的“产品含税单价 140”和回收期基准 4.5 / 5 年都是教学假设。

第 1 步：打开工具，载入教学案例

目标：让页面里出现一套完整、可核对的教学数据。

  1. 打开在线工具

    https://bclee012.github.io/project-financial-analysis/

  2. 第一次进入会看到「使用方法」页

    点击页面上的「开始体验教学案例 →」。如果你已经保存过数据，直接点顶部「使用方法」页签也能找到这个按钮。

  3. 页面跳到「参数录入」

    顶部案例行应显示：虚拟教学案例 · 教学案例：新建生产项目。

你会看到：11 个参数区。01–04、06–07、11 默认展开；05 折旧与摊销、08 流动资金、09 利润分配、10 逐年所得税默认收起。收起的区块仍然参与计算，不会“失效”。
为什么不用默认显示的真实案例？ 页面首次打开时可能显示【真实·资料映射】某县第三供水厂。它用于展示真实案例的长表单，但部分参数是按公开资料估算的。本说明选择虚拟教学案例，是为了让你能用固定数字核对操作。
想看真实案例？ 在参数录入页的「内置案例」里选择【真实·资料映射】专项债案例：某县第三供水厂，或【真实·可研复算】真实试点：福建建阳供水设施及管道提升工程，再点「载入案例」。标签表示数据来源和假设强度，不表示项目现状或可行性结论。

第 2 步：生成第一份基线报告

目标：先看清“原价 140”时，各项指标是什么状态。

  1. 点击「生成评估报告」

    右上角或表单底部都可以。页面会切换到「评估报告」。

  2. 先看最上面的「评估结论一览」

    每张卡片是一个判断指标：指标值、判断标准，以及“达标 / 未达标 / 不适用”。

  3. 再看「综合结论」

    所有适用判断指标都没有出现“未达标”，才显示“项目财务可行”；只要有一项适用指标未达标，就显示“财务可行性未完全满足”。现行口径下，无相应债务时 ICR / DSCR 会标为“不适用”，不参与达标判断。

综合结论是“未完全满足”，不是软件出错。 这个教学案例的 NPV 和 IRR 达标，但回收期 5.12 / 5.65 年超过了教学假设的 4.5 / 5 年。报告要求所有适用判断指标一起看，不能只挑一个好看的指标；“不适用”也不能当作“达标”。

页面向下还有「第一次读报告：这些结果怎么理解？」，用三句话解释 NPV、IRR 和回收期。第一次读报告，建议先看这一段，再看后面的 18 个正文章节和附录。

数字对不上？ 确认三件事：案例是【虚拟】教学案例、含税单价仍是 140、没有改过其他字段。页面显示会四舍五入，尾差在 0.01 左右是正常的。

第 3 步：保存方案 A，改价，再保存方案 B

目标：只改一个参数，观察结果怎么变。

先保存基线为方案 A

  1. 点击「← 返回修改参数」

    回到参数录入页。

  2. 点击「保存当前为方案」

    会弹出“保存一个方案版本”对话框。

  3. 把名称改成「A 原价 140」，点击「保存方案」

    “我的方案”计数会增加 1。保存的是当前参数，不是报告文件。

再把含税单价从 140 改为 126

  1. 用快捷导航跳到「07 营业收入与税金」

    在参数区上方的一排快捷按钮里点击它，页面会滚动到对应区块。

  2. 找到「产品含税单价 万元/吨」

    当前值是 140。把它改成 126（降低 10%），按 Tab 或点击空白处。

  3. 点击「生成评估报告」

    报告会按新价格重新计算。

只改含税单价的前后对照
指标原价 140降价 126变化
全部投资 NPV1,820.39 万元−176.05 万元由正转负
全部投资 IRR14.64%9.53%低于 10% 基准
静态回收期5.12 年5.40 年变长
动态回收期5.65 年计算期内未回收无法在计算期收回
这就是敏感性：在其他参数不变时，售价下降 10%，收入减少，NPV 和 IRR 下降，回收期变长。只改一个参数，才能把结果变化归因到这个参数。

然后返回参数录入页，再次点击「保存当前为方案」，命名为「B 降价 126」。现在你有两个版本可以对比。

保存前会检查输入。 如果有红色错误提示，先按提示修正对应字段；错误字段在折叠区时，页面会自动展开并定位。

第 4 步：对比方案 A 和 B

目标：把两个版本的差异放在一张表里看。

  1. 点击顶部「方案对比」

    页面会出现两个下拉框。

  2. 左边选「A 原价 140」，右边选「B 降价 126」

    下拉框里还会有一项“当前参数”，它是你正在编辑、尚未保存的版本。

  3. 点击「开始对比」

    页面显示并排指标表、净现值和收益率对比图，以及雷达图；较优的一项会高亮。

怎么读：先看 NPV、IRR、回收期这三类；再看资本金指标和偿债指标。A 的收益指标更好，B 的收益指标更差，说明降价会削弱项目财务表现。对比页的判断只针对这两组参数，不代表现实中的最优方案。
管理方案：在参数录入页的“我的方案”里可以载入、删除；删除后可以用「撤销删除方案」恢复。载入、恢复默认和导入备份前，系统会保留一次可撤销的参数。撤销只在当前页面会话内有效，刷新后不会保留。

第 5 步：导出报告与下载备份

目标：把结果带走，并且能在另一台电脑继续编辑。

导出方式适合做什么注意
Excel 报表继续计算、留档、检查各张报表包含多张工作表；不是每个单元格都是公式
Word（.docx）交作业、修改文字、插入自己的封面图表以图片嵌入；在 Word / WPS 中检查分页
交互式 HTML发给别人离线查看，保留图表和敏感性滑杆单个文件；图表和滑杆脚本已内嵌，可离线打开；字体等外观可能因本机环境略有差异
打印 / 保存为 PDF最终提交、打印在打印对话框选择“另存为 PDF”
  1. 在报告页右上角选择一种导出

    按钮会变成“正在生成…”，完成后浏览器会下载文件。

  2. 打开下载的文件检查

    重点看：项目名称、NPV / IRR、表格是否完整、图表是否显示。

  3. 保存为 PDF

    点击「打印 / 保存为 PDF」→ 目标打印机选“另存为 PDF”→ 保存到指定文件夹。

导出失败怎么办？ 参数不会丢。先重试；再换 Chrome / Edge；仍失败就用“打印 / 保存为 PDF”，并下载项目备份。把错误提示和浏览器版本一并反馈，便于定位。

下载项目备份

  1. 回到参数录入页，点击「下载项目备份」

    得到一个 JSON 文件，里面是当前参数，不是报告文件。

  2. 换电脑时，在新电脑打开工具，点击「导入项目备份」

    选择这个 JSON；导入成功后会恢复参数，再点「生成评估报告」即可。

项目备份 ≠ 云端同步。 浏览器里的自动暂存和“我的方案”不会跨设备同步；备份文件需要你自己保存和传输。备份只包含当前参数，不包含“我的方案”列表；下载前要求当前参数通过校验。文件上限 1 MB；格式不对的备份不会覆盖当前数据。

常见问题

先看这里，大多数问题都能自己解决。

第一次打开，为什么停在「使用方法」？

这是正常的首次引导：浏览器里还没有保存过数据时，系统会先打开使用方法页。点击「开始体验教学案例」即可进入练习；也可以直接点顶部「参数录入」开始填写。

默认显示的案例，为什么不是这份说明里的教学案例？

页面首次打开时可能显示【真实·资料映射】某县第三供水厂，用于展示真实案例的长表单；它的部分参数是按公开资料估算的。本说明为了让你能用固定数字核对操作，改用【虚拟】教学案例。重新载入的方法：参数录入页 → 内置案例 → 选择【虚拟】基准案例（现行规范）→ 载入案例。

注意：顶部「恢复默认案例」会载入默认的真实资料映射案例，不是这份说明的虚拟教学案例。

我的结果和 1,820.39 / −176.05 不完全一样，怎么办？

先确认三件事：案例是【虚拟】教学案例；含税单价只从 140 改成 126；没有改过其他字段。页面显示会四舍五入，尾差在 0.01 左右是正常的。如果你改了建设期、运营期、税率、借款比例、基准收益率或负荷，结果本来就会不同。

刷新页面或关掉浏览器，数据还在吗？

在同一个浏览器、同一个网址下，自动暂存和“我的方案”通常会保留。但清理浏览器数据、使用无痕模式、换浏览器或换电脑后，不会自动带过去。重要数据请下载项目备份。

换电脑 / 换浏览器，怎么继续？

在旧电脑下载「项目备份」JSON，在新电脑打开工具，点击「导入项目备份」选择该文件。备份只包含当前参数，不包含“我的方案”列表；方案列表不会随备份迁移。导入前会检查文件格式和参数，格式不对不会覆盖当前数据。

报告能直接用于项目审批吗？

不能直接替代。报告是依据《建设项目经济评价方法与参数》（第三版）编制的财务评价专章，结果取决于你录入的参数、案例映射和判断基准。它不包含市场、技术、节能、环保、社会稳定等专项论证，也不能替代可行性研究、审批或投资决策。真实案例标签也不表示项目现状或实际可行性。

NPV 是负数、IRR 显示“—”、回收期“未回收”，是坏了吗？

不是软件故障。NPV 为负表示在当前参数和基准收益率下，折现后的净收益为负；IRR 显示“—”可能是现金流在求解区间内找不到收益率，不代表收益为零，也不能视为达标；回收期“未回收”表示在所设计算期内没有收回投入，不能当作 0 年，报告会按未达标处理。先检查收入、成本、投资、税率和基准收益率，再看报告中的说明。

修改建设期或运营期后，为什么表单变长 / 变短了？

生产负荷、投资分配、借款比例和逐年所得税都是分年数组。修改年限后，系统会按有效范围补齐或截断这些数组，并给出提示。请重新检查各年负荷、投资分配和税率是否符合你的项目。

导出没反应，或者图表不显示，怎么办？

先等几秒，确认浏览器没有拦截下载；再刷新页面重试；推荐使用 Chrome 或 Edge。仍失败时，改用「打印 / 保存为 PDF」，并下载项目备份保留参数。如果交互式 HTML 在另一台电脑打开后图表空白，确认文件完整、用现代浏览器打开，并且没有禁用本地脚本。

手机上能用吗？

页面会适配窄屏，可以查看和简单修改；但参数表、报告宽表和导出操作在手机上体验有限。完整走一遍流程，建议使用电脑浏览器。

指标小抄

不需要背公式，先知道每个指标在回答什么问题。

指标一句话理解怎么读
NPV
净现值		计算期内各年净现金流按基准收益率折现后的代数和。在采用该基准收益率的前提下，NPV ≥ 0 表示达到基准要求；单位通常为万元。
IRR
内部收益率		使项目净现值（NPV）等于 0 的折现率。与基准收益率比较；不是“利润率”；“—”表示求解区间内未找到，不等于 0，也不能视为达标，应复核现金流。
静态回收期不考虑资金时间价值，累计净现金流由负转正所需的时间。越短通常越好；是否可接受取决于基准回收期。
动态回收期按基准收益率折现后，累计折现净现金流由负转正所需的时间。在折现率为正且现金流常规时，动态回收期不短于静态回收期；“未回收”表示计算期内没收回，按未达标处理。
总投资收益率正常年息税前利润（EBIT）÷ 项目总投资。本工具中 EBIT＝利润总额＋计入总成本费用的利息；总投资＝建设投资＋建设期利息＋流动资金；正常年取首个达产年，未达产时取负荷最高年（原表口径除外）。参考指标，不是唯一判断。
盈亏平衡点在正常年价格和成本结构下，使利润总额为零的生产能力利用率。现行口径按“固定成本 ÷ 满产贡献额”计算，满产贡献额＝满产营业收入−税金及附加−可变成本；原表口径按该年贡献额。在价格和成本结构不变时，BEP 越低，抗产量下降风险的能力通常越强。
ICR
利息备付率		息税前利润（EBIT）÷ 计入总成本费用的利息支出。≥ 1 表示 EBIT 能覆盖利息；无相应利息时不适用。
DSCR
偿债备付率		（净利润＋折旧＋摊销＋利息）÷ 当期应还本付息额。≥ 1 表示可用于还本付息的资金能覆盖当期应还本付息额；无相应债务时不适用。
资本金 IRR / NPV以资本金现金流量为基础，反映自有资金在还本付息后的回报。与全部投资指标分开看；借款比例、利率和还款安排会影响资本金指标。
基准收益率用于折现和判断项目是否达到最低收益要求的收益率。它是输入假设，不是系统自动给出的行业标准；本工具的教学默认值仅用于练习，实际项目要说明取值依据。
一句话总结：NPV 看按基准折现后的净价值，IRR 看内部收益率相对基准的高低，回收期看多久回本，ICR / DSCR 看还本付息压力。任何单一指标都不能代替完整判断。
